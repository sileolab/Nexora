Nexora Python SDK Reference

Official, production-grade Python client for the Nexora Studio & Data Engineering Platform. Automate large-scale web crawling, multi-engine content extraction, anti-bot bypass, semantic RAG vector pipelines, and autonomous real-time live extraction with clean Pythonic APIs.

Package: nexora Version: 4.0.0 Python: >= 3.9 Thread-Safe: Yes Async & Sync: Supported

Overview & Architecture

The nexora Python package provides a cohesive, developer-friendly interface to all platform services. Instead of stitching together dozens of disparate scraping libraries, proxy managers, text cleaners, chunkers, and embedding providers, Nexora unifies the entire lifecycle under a single client:

Web & Live Ingestion

Multi-Engine Web & Live Watchers

Smart cascaded routing across Playwright, Crawl4AI, and Trafilatura, plus Live Watchers with autonomous dynamic field mutation detection.

RAG Engineering

Semantic AI & Hybrid Search

Semantic boundary chunking, grammatical smoothing, vector embeddings (OpenAI, Gemini, Ollama, DeepSeek), and hybrid BM25 + dense retrieval.

Installation & Setup

Install the library directly in your Python environment or virtualenv:

Terminal / Bash 
# Install in development/editable mode from repository root:
pip install -e .

# Or install with optional headless browser automation dependencies:
pip install "nexora[playwright]"
playwright install chromium
Backward Compatibility Note: Existing code importing from nexora.client import CrawlbotClient continues to work seamlessly as a drop-in alias for NexoraClient.

NexoraClient Initialization

Instantiate NexoraClient by pointing to your local or hosted Nexora server instance:

Python 3 
from nexora import NexoraClient

# 1. Default local server connection
client = NexoraClient(base_url="http://127.0.0.1:8000")

# 2. Production setup with API Key, custom timeout and tenant workspace
client = NexoraClient(
    base_url="https://api.nexora.internal",
    api_key="nx_live_9f82a17b0c",        # Passed as X-API-Key / Bearer header
    workspace_id="ws_finance_prod",      # Multi-tenant isolation context
    timeout=45.0,                         # HTTP timeout in seconds
    default_headers={"X-App-Env": "production"}
)

# Verify server health and connectivity:
status = client.health()
print(f"Nexora Server Status: {status['status']} | v{status.get('version')}")

Constructor Parameters

URL Discovery & Website Crawling

Discover pages across any domain respecting robots.txt and sitemaps, or start full background crawls:

Python 3 
# Method 1: Instant URL discovery (Sitemaps + Robots.txt + Link traversal)
discovery_job = client.discover_urls(
    root_url="https://example.com",
    max_depth=3,
    max_pages=100,
    include_patterns=[r"^https://example\.com/blog/.*"],  # Regex filters
    exclude_patterns=[r".*\?(utm_source|ref)=.*"],
    browser_fallback=True  # Fallback to Chromium on anti-bot challenge
)
print(f"Started Discovery Job ID: {discovery_job.id}")

# Block until completed and fetch all discovered links:
job_status = client.wait_for_job(discovery_job.id, timeout=120.0)
print(f"Found {len(job_status.discovered_urls)} URLs!")

# Method 2: Full end-to-end background crawl & document extraction
crawl_job = client.crawl_website(
    start_url="https://news.ycombinator.com",
    max_pages=30,
    strategy="auto"  # 'auto', 'playwright', 'crawl4ai', 'trafilatura'
)

4-Engine Content Extraction

Nexora executes a smart cascaded strategy to reliably parse web pages regardless of anti-scraping or JavaScript frameworks:

Python 3 
# Single-pass synchronous extraction with engine selection:
doc = client.extract_content(
    url="https://en.wikipedia.org/wiki/Artificial_intelligence",
    strategy="auto",  # Adaptive Cascade Router
    css_selector="#mw-content-text",  # Optional CSS scope

)

print(f"Title: {doc.title}")
print(f"Text Length: {len(doc.cleaned_text)} characters")
print(f"Engine Used: {doc.metadata.get('engine_used')}")

Semantic Chunking & AI Repair

Prepare extracted documents for Retrieval-Augmented Generation (RAG) with boundary-aware chunking and grammar smoothing:

Python 3 
# 1. Segment extracted documents into semantic chunks
chunk_summary = client.chunk_job(
    job_id=crawl_job.id,
    chunk_size=500,        # Target tokens per chunk
    chunk_overlap=50,      # Sliding token overlap
    strategy="token"       # 'token', 'sentence', or 'hierarchical'
)
print(f"Created {chunk_summary['total_chunks']} chunks.")

# 2. Semantic boundary repair (smooths cut-off sentences & header context)
repair_result = client.repair_chunks(job_id=crawl_job.id)
print(f"Repaired Chunks: {repair_result.get('repaired_count', 0)}")

# 3. Generate dense vector embeddings
embed_result = client.embed_chunks(
    job_id=crawl_job.id,
    model="text-embedding-3-small"  # OpenAI, Google Gemini, Ollama, or DeepSeek
)

Hybrid Search (BM25 + Dense Vectors)

Query your RAG index using hybrid Reciprocal Rank Fusion (RRF) for industry-leading recall:

Python 3 
# Execute hybrid search across embedded chunks:
hits = client.search(
    job_id=crawl_job.id,
    query="What are the quarterly net margins and projections?",
    top_k=5,
    method="hybrid",         # 'hybrid', 'dense' (cosine), or 'bm25' (lexical)
    alpha=0.7,               # 0.0 = 100% BM25, 1.0 = 100% Vector similarity
    expand_neighbors=True    # Include preceding and succeeding chunks for LLM context
)

for idx, hit in enumerate(hits, 1):
    print(f"[{idx}] Score: {hit.score:.4f} | Source: {hit.source_url}")
    print(f"    Text: {hit.text[:120]}...
")

Live Watchers & Autonomous Auto-Detect

For fast-moving websites (crypto exchanges, stock tickers, e-commerce pricing, auction desks, flight portals), use the client.live namespace. It monitors pages at sub-second frequencies, replaces stale data with live state, and features Autonomous Dynamic Field Detection (Auto-Detect).

A. Zero-Selector Auto-Detect Mode (Recommended)

Nexora automatically observes the page, identifies changing metrics (Bitcoin price, 24h volume, market cap, stock availability), and infers CSS selectors without you needing to write any code:

Python 3 
from nexora import NexoraClient

client = NexoraClient(base_url="http://localhost:8000")

# Autonomous Live Watcher on CoinMarketCap Bitcoin (Zero CSS selectors needed!):
for event in client.live.watch(
    url="https://coinmarketcap.com/currencies/bitcoin/",
    auto_detect=True,          # Autonomous scanner: discovers price, cap, volume
    observation_seconds=3.0,   # Initial observation window
    interval_seconds=2.0       # Live polling frequency
):
    print(f"[{event.timestamp}] Live Mutation #{event.change_count}")
    print(f"  Changed Fields: {event.diff}")
    print(f"  Current Live State: {event.latest_data}
")

B. Standalone Field Scanner (Discover Selectors)

Python 3 
# Scan any webpage to discover dynamic fields and extract recommended CSS selectors:
scan_result = client.live.auto_detect(
    url="https://coinmarketcap.com/currencies/bitcoin/",
    observation_seconds=3.0
)

print(f"Discovered {len(scan_result.detected_fields)} dynamic fields:")
for field in scan_result.detected_fields:
    mutation_tag = "[MUTATION]" if field.mutation_detected else ""
    print(f"  • {field.name:20} -> Value: '{field.sample_value}' | Selector: {field.selector} {mutation_tag}")

print("Recommended Selectors:", scan_result.recommended_selectors)

C. Explicit Manual CSS Selectors

Python 3 
# Custom targeted watcher:
watcher = client.live.create(
    url="https://example.com/store/item-123",
    name="Product Price Watcher",
    selectors={"price": ".current-price", "stock": "#stock-status"},
    interval_seconds=5.0,
    single_trigger=False,
    turn_on=True
)

# Query latest snapshot at any time (stale data was purged):
latest = client.live.get_latest(watcher.id)
print("Latest State:", latest['latest_data'])

# Turn OFF when finished:
client.live.turn_off(watcher.id)

Single-Trigger Auto-Stop Mode

In single-trigger mode (single_trigger=True), the watcher wakes up, continuously inspects the page, and the exact microsecond a change occurs:

  1. Replaces the previous data with the fresh live state.
  2. Emits the LiveChangeEvent notification via SSE and webhooks.
  3. Immediately turns OFF to avoid unnecessary bandwidth and server overhead.
Python 3 
# Snipe a concert ticket or product restock:
for event in client.live.watch(
    url="https://tickets.example.com/festival",
    selectors={"status": ".inventory-status"},
    interval_seconds=1.0,
    single_trigger=True   # Automatically turns OFF after first detected change
):
    print(f"🚨 Ticket state changed! New Status: {event.latest_data['status']}")
    # Loop ends and watcher automatically turns OFF

Blueprint 2: Enterprise RAG Knowledge Base Assistant

Crawls an organization's documentation, chunks, repairs grammar, generates embeddings, and performs hybrid search:

enterprise_rag.py 
from nexora import NexoraClient

def build_knowledge_base(doc_url: str):
    client = NexoraClient(base_url="http://localhost:8000")

    # Step 1: Crawl website
    job = client.crawl_website(start_url=doc_url, max_pages=25, strategy="auto")
    client.wait_for_job(job.id, timeout=180.0)

    # Step 2: Semantic Chunking
    client.chunk_job(job.id, chunk_size=400, chunk_overlap=40)

    # Step 3: Grammatical Smoothing & Boundary Repair
    client.repair_chunks(job.id)

    # Step 4: Vector Embeddings
    client.embed_chunks(job.id, model="text-embedding-3-small")

    # Step 5: Hybrid Retrieval Query
    results = client.search(
        job_id=job.id,
        query="How do I configure custom proxy authentication?",
        top_k=3,
        method="hybrid",
        alpha=0.75
    )

    for r in results:
        print(f"Score: {r.score:.4f} | URL: {r.source_url}")
        print(f"Chunk: {r.text}
")

if __name__ == "__main__":
    build_knowledge_base("https://docs.example.com")

Blueprint 3: Competitor Price Tracker & Auto-Repricer

dynamic_repricer.py 
from nexora import NexoraClient

def reprice_competitor_item(competitor_url: str, my_base_cost: float):
    client = NexoraClient(base_url="http://localhost:8000")

    # Continuous watcher for competitor discounts:
    for change in client.live.watch(
        url=competitor_url,
        selectors={"price": ".product-price, [data-qa='price']"},
        interval_seconds=10.0
    ):
        raw_price = change.latest_data.get("price", "$0")
        numeric_price = float(raw_price.replace("$", "").replace(",", ""))

        # Auto-Reprice rule: Beat competitor by 2% while protecting minimum margin
        optimal_price = max(my_base_cost * 1.10, numeric_price * 0.98)
        print(f"Competitor Price: ${numeric_price} ➔ Updated My Price: ${optimal_price:.2f}")

Exception Hierarchy

All exceptions thrown by the SDK inherit from NexoraError for predictable error handling:

Exception ClassBaseWhen Raised
NexoraErrorExceptionBase exception for all errors raised by the library.

NexoraAuthenticationErrorNexoraAPIErrorHTTP 401/403 status indicating missing or invalid API key.
NexoraNotFoundErrorNexoraAPIErrorHTTP 404 status when a job, document, or watcher is not found.
