Platform Architecture & Security

Overview

Nexora is an enterprise-grade Autonomous Web Intelligence, RAG Ingestion, and Information Retrieval Platform built with FastAPI, Playwright Chromium, Crawl4AI, and Vector Storage.

End-to-End System Pipeline

Nexora unifies multi-depth web discovery, multi-engine headless rendering, semantic chunking, and dense-lexical hybrid search into an integrated developer portal.

Discovery Engine
Smart XML sitemap crawler, robots.txt compliance, regex url pattern routing, and multi-depth link extraction.
Extraction Studio
4 extraction engines: Smart Auto with fallback, Playwright Chromium headless, Crawl4AI, and Trafilatura.
AI & RAG Pipeline
Persian & multilingual normalization, semantic token chunking, automatic repair, and multi-provider embeddings.
Evaluation Studio
Rigorous IR metrics (Recall@K, MRR, nDCG@K), 3-method comparative benchmarking, and candidate exclusion tracing.

Authentication & Workspace Isolation

Nexora supports two authentication schemes and strict workspace multi-tenancy. You can authenticate via HTTP headers on every request:

Header Format Description
X-API-Key cbk_live_xxxxxxxx Workspace API key for client access, or master admin secret for platform administration.
Authorization Bearer cbk_live_xxxxxxxx Standard RFC 6750 Bearer token format accepted interchangeably with X-API-Key.
X-Workspace-Id ws_xxxxxxxx Optional tenant scoping header. When using workspace API keys, tenant is resolved automatically.

Standard API Response Envelope

Every REST API endpoint in Nexora returns a predictable, type-safe envelope format:

{ "success": true, "message": "Operation completed successfully", "data": { "job_id": "job_d9a8f2e1", "status": "running" }, "error": null }

 Nexora Python SDK Installation & Quickstart

          
Install the SDK into your active Python environment:

          

            
pip install nexora

          

          
Initialize the client and run an end-to-end extraction and semantic chunking workflow:

          

            
from nexora import NexoraClient

# 1. Initialize client
client = NexoraClient(
    base_url="http://localhost:8000",
    api_key="your_workspace_or_admin_key"
)

# 2. Check system health
health = client.health()
print(f"Connected to Nexora: {health['status']}")

# 3. Trigger content extraction
job = client.extraction.start(
    urls=["https://example.com/article"],
    engine="auto",
    crawl_mode="single"
)

# 4. Chunk text semantically
chunks = client.rag.chunk_text(
    text="# Title\n\nDetailed content for vector indexing...",
    chunk_size=500,
    chunk_overlap=50
)
print(f"Generated {len(chunks)} semantic chunks")

          

        


        

          
 Nexora Developer CLI Quickstart

          
Execute autonomous crawling, extraction, vector indexing, and benchmarks directly from your terminal:

          

            
# 1. Inspect CLI help and available command groups
nexora --help

# 2. Start a website discovery crawler
nexora crawl --url https://example.com --max-depth 3 --max-pages 50

# 3. Extract structured markdown from URLs using Playwright headless
nexora extract --url https://example.com/blog --engine playwright

# 4. Ingest and semantically chunk a document file
nexora files process --path ./manual.pdf --chunk --embed

# 5. Run Information Retrieval benchmark evaluation
nexora eval run --dataset ds_default --top-k 5
